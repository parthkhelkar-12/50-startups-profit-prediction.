# 50-startups-profit-prediction.
Machine Learning project to predict startup profits using Python and Linear Regression.

## Project Overview
This project explores startup financial data and aims to predict company profit using Machine Learning regression techniques.

## Objectives
- Explore relationships between startup expenditure and profit.
- Perform data cleaning and exploratory data analysis (EDA).
- Build and evaluate a regression model.
- Understand how financial features relate to predicted profitability.

## Dataset
The dataset contains startup financial information, including:
- R&D Spend
- Administration
- Marketing Spend
- State
- Profit

## Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Approach
1. Load and inspect the data.
2. Clean and preprocess the data.
3. Perform exploratory data analysis.
4. Prepare features and target variable.
5. Train a regression model.
6. Evaluate predictions using MAE, RMSE and R².
